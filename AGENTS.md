# vid-loomz

Shared policy: `/Users/lap/Development/agent-rules/AGENTS.md`. This file holds only this repository's facts.

Standalone Python utilities for video conversion, download and browser recording, shaped for game-engine render-sequence automation. `README.md` owns the commands, flags and formats.

- The tools are the scripts in `src/`. `python3 src/setup.py` installs ffmpeg, yt-dlp, Playwright with Chromium and, on macOS, create-dmg.
- TypeScript: nothing here runs on a JavaScript runtime.
